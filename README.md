# 딜싸이클 용사

> 다섯 관문을 부수고 마왕에게 닿아라. 고르지 않은 카드는 전부 마왕의 다섯 칸이 된다.

Godot으로 만든 실시간 액션 로그라이크입니다.
5칸짜리 딜싸이클 레일 위를 **바늘**이 돌며 카드를 냅니다.
칸에 붙인 **각인**이 바늘을 한 칸 되돌리고, 한 칸 건너뛰고, 같은 칸을 한 번 더 밟게 해
한 바퀴의 길이 매번 달라집니다.
카드에는 **속성**이 있어서 5칸에 놓는 **순서 자체가 콤보**가 됩니다 — 기름을 칠하고 불을 붙입니다.

이 프로젝트는 웹페이지가 아니라 Godot 게임입니다. `http://localhost:5173`은 이전 실험이므로 사용하지 않습니다.

---

## 가장 쉬운 실행 방법

1. Mac의 `응용 프로그램` 폴더에서 Godot을 엽니다.
2. 프로젝트 목록에서 `Import`를 누릅니다.
3. `/Users/moomi/orca/projects/NHN/godot-game/project.godot`을 선택합니다.
4. `Import & Edit`를 누릅니다.
5. 편집기 오른쪽 위의 삼각형 재생 버튼을 누릅니다.
6. 별도 창에 나타나는 `딜싸이클 용사`에서 모험을 시작합니다.

터미널로 실행하려면 다음 명령을 사용합니다.

```bash
cd /Users/moomi/orca/projects/NHN
godot --path godot-game
```

## 게임의 규칙

### 다섯 개의 스테이지

한 스테이지는 **무한 필드 + 성 1 + 베이스캠프 1 + 보스방 1**로 이루어집니다.
파밍을 하다가 준비가 됐다고 판단하면 보스방에 들어갑니다. 캠프는 보스문보다 반드시
먼저 만나며 성과 같은 정비 공간에 **스테이지당 완전 회복 1회**를 더 줍니다.

| 스테이지 | 이름 | 분위기 | 낮/밤 | 관문의 주인 |
|---|---|---|---|---|
| 1 | 왕국 변두리 | 초원 | 72 / 45초 | **서릿발 외눈** (얼음 + 번개) |
| 2 | 시든 숲 | 초원 · 채도 낮춤 | 68 / 52초 | **역병 점액왕** (독) |
| 3 | 잿빛 벌판 | 황야 · 안개 | 62 / 60초 | **홍염 천구** (불 + 기름) |
| 4 | 역병의 늪 | 황야 · 초록 장막 | 56 / 68초 | **흑점액 변종** (강화형) |
| 5 | 심연 | 자줏빛 · 비네트 | 48 / 78초 | **흑천구** (강화형) |

스테이지가 오를수록 화면이 험악해집니다. **가장 강한 연출은 필터가 아니라 시간입니다** —
5스테이지는 한 주기의 62%가 밤이라 거의 항상 어둡습니다.

**5스테이지 보스를 잡으면 그 자리에서 곧바로 마왕전이 열립니다.**

### 기한은 없습니다. 대신 오래 머물면 손해입니다

총 일수는 **기록용 숫자**이고 승리 등급만 그 값을 봅니다. 압박을 만드는 것은
**체류(dwell)** — 지금 스테이지에서 낮/밤을 몇 번 넘겼는가 — 하나입니다.

| 체류 | 몹 체력 | 몹 피해 | 경험치 | **킬당 효율** |
|---:|---:|---:|---:|---:|
| 0 | ×1.00 | ×1.00 | ×1.00 | **1.000** |
| 4 | ×1.68 | ×1.34 | ×1.32 | **0.772** |
| 8 | ×2.68 | ×1.82 | ×1.70 | **0.611** |
| 12 | ×4.00 | ×2.42 | ×2.10 | **0.500** |

몹 체력은 무한히 오르는데 경험치는 그 **제곱근**으로만 오릅니다.
체류 12면 같은 레벨을 올리는 데 **시간이 두 배** 듭니다.
스테이지를 넘기면 체류가 **절반으로 줄어 이월**됩니다 — 완전한 사면도, 무자비한 이월도 아닙니다.

승리 등급은 총 일수로 정해집니다: **13일 이내 S · 17일 이내 A · 23일 이내 B · 그 뒤 C.**
기대 플레이는 15~20일입니다.

### 5칸 딜싸이클과 바늘

레일은 **5칸 고정**이고 가로 스크롤이 없습니다. 런 시작부터 5칸이 전부 열려 있습니다.

```text
[ 칸1 ] ─ [ 칸2 ] ─ [ 칸3 ] ─ [ 칸4 ] ─ [ 칸5 ]
                      ▼ 바늘 (지금 실행 중)
```

- 바늘이 있는 **한 칸만** 나갑니다. 가진 스킬이 동시에 터지지 않습니다.
- 빈 칸은 빈 행동이 아니라 **기본 베기**를 냅니다.
- **한 칸은 한 바퀴에 두 번까지만 밟힙니다.** 각인이 세 번째를 만들려 해도 조용히 버려집니다.
  그래서 한 바퀴는 아무리 길어도 **10스텝**을 넘지 않습니다.
- 5칸을 통과하면 한 바퀴가 끝나고 **RELOAD**에 들어갑니다.

### 속성 콤보 — 순서가 곧 콤보입니다

카드는 **불 · 얼음 · 번개 · 독 · 기름** 다섯 속성과 나머지 둘(**타격 · 정신**)로 나뉩니다.
일곱 속성은 화면에서 **색으로** 갈립니다 — 빨강 · 하늘 · 노랑 · 연두 · 갈색 · 회색 · 자주.
맞은 적에게는 상태가 남고, **그 위에 무엇을 꽂느냐**가 결과를 바꿉니다.

| 상태 | 하는 일 |
|---|---|
| **독** | 서서히 아픕니다. 유일하게 **중첩**됩니다(최대 6) |
| **연**(불) | 짧고 굵게 아픕니다 |
| **한**(얼음) | 느려집니다. 전도와 증기의 재료입니다 |
| **유**(기름) | **그 자체로는 아무 피해도 없습니다.** 오직 불과만 의미가 있습니다 |
| **전**(번개) | 다음 한 대가 더 아픈 표식입니다 |

| 조합 | 화면에 뜨는 말 | 결과 |
|---|---|---|
| **기름 → 불** | 크게 타오름! | 불의 세기 ×3 · 지속 ×2.5 · 주변에 기름이 번집니다. **맨 불의 7.5배** |
| **얼음 → 번개** | 번개 옮음! | 얼어 있는 적에게만 최대 4마리까지 옮아갑니다 |
| 독 → 불 | 역병에 불! | 쌓인 독을 전부 태워 넓게 터뜨립니다 |
| 얼음 → 불 | 증기! | 얼음이 풀리는 대신 이번 타격 범위가 넓어집니다 |
| 얼음 → 타격 | 얼음 깨짐! | 얼음이 풀리는 대신 밀치기 두 배 + 경직 |
| 독 → 타격 | 터뜨리기! | 쌓인 독 하나를 즉시 피해로 바꿉니다 |
| 아무 상태 → 정신 | 정신 붕괴! | 남은 상태 지속을 모두 갉아 피해로 바꿉니다 |

**타격과 정신 둘은 상태를 만들지 않고 거둬들입니다.** 그래서 자연히 5칸의 **뒤쪽 마무리 칸**에
놓이게 되고, 그것이 "순서가 콤보"라는 말의 실체입니다.

상태는 **나에게도 쌓입니다.** 보스가 독을 뿌리고 기름을 끼얹습니다.

### 각인 15종 — 열은 칸에, 다섯은 레일 전체에

각인은 카드가 아니라 **칸**에 붙습니다. 칸을 통째로 옮기면 각인이 함께 따라가고,
카드만 옮기면 각인은 그 칸에 남습니다.

**칸 각인 10종** — 그 한 칸에만 붙습니다.

| 계열 | 각인 |
|---|---|
| 흐름 | 두 번 치기 · 한 칸 뒤로 · 한 칸 건너뛰기 · 두 번 치고 건너뛰기 · 마무리 |
| 전투 | 힘주기(피해) · 넓히기(범위) |
| 속도 | 서두르기(이 칸은 쉬는 시간을 안 만든다) |
| 조건 | 첫 칸 힘(이번 바퀴에 처음 밟는 칸이면 크게) |
| 동시 | 쌍둥이(앞 칸 기술도 절반 힘으로 같이) |

**레일 각인 5종** — 5칸 전체에 한 번에 걸립니다. 레일에는 3개까지, 같은 것은 하나만.

| 각인 | 하는 일 |
|---|---|
| 빨리 감기 | 모든 칸이 조금 빨리 끝납니다 |
| 모두 힘주기 | 모든 칸 피해가 조금 늡니다 |
| 짧은 휴식 | 한 바퀴의 쉬는 시간이 줍니다 |
| 같은 색 덤 | 같은 색이 옆에 붙은 칸의 피해가 늡니다 |
| 되돌이 | 마지막 칸을 지나면 **거꾸로 한 바퀴 더** 돕니다 |

- 한 칸에 각인을 **쌓을 수 있습니다.** 다만 4겹 감쇠(스택 5 / 같은 각인 3 /
  중복 확률 0.55배씩 / 4개째부터 그 칸 전체 확률 ×0.80)가 걸려 몰빵이 유일 정답이 되지 않습니다.
- 같은 각인이라도 뽑을 때마다 확률과 크기가 다릅니다.
- 등급은 **일반 6 · 희귀 6 · 영웅 3**입니다.

### RELOAD 빚 — 많이 밟을수록 오래 쉽니다

한 바퀴 동안 낸 카드의 쉬는 시간이 **빚**으로 쌓이고, 바퀴가 끝나면 그만큼 쉽니다.

- 각인이 바늘을 되돌리고 한 칸을 두 번 밟게 만들수록 **한 바퀴가 길어지고 빚도 늡니다.**
  더 많이 때리는 값을 더 긴 침묵으로 치릅니다 — 이것이 밸런스의 뼈대입니다.
- 무각인 5칸 기준선은 **약 2.42초**입니다.
- 스테이지 보스는 이 빚의 0.90배(강화형 0.60배), 마왕은 **0.42배**만 쉽니다.

속성 태그는 이 위에 한 겹 더 얹힙니다: **공명** — 인접한 두 칸이 같은 속성이면 둘 다 +15%.

### 관문의 주인 — 보스 세 종류

스테이지 보스는 **당신과 같은 딜싸이클을 돌립니다.** 다만 5칸이 아니라 **3칸**(강화형 4칸)이고
각인이 없습니다. **5칸과 각인은 마왕만의 것입니다.**

- 패턴마다 **0.35~1.20초의 예비 동작**이 있고 바닥에 예고 링이 뜹니다.
  **링이 뜬 자리가 곧 착탄점입니다.** 보고 피할 수 있습니다.
- 체력이 절반이 되면 **페이즈**가 넘어가 예비 동작이 짧아지고 피해가 커집니다(강화형은 두 번).
- 보스도 콤보를 씁니다. 홍염 천구는 **기름을 끼얹고 불을 붙입니다** —
  당신이 3스테이지에서 당한 콤보를 5스테이지에서는 자기 5칸으로 되갚게 됩니다.
- 보스방 앞에서 **프리뷰**로 상대의 칸을 미리 보고 `ESC`로 물러설 수 있습니다.
- 한 관문은 **30~60초**, 마왕은 **60~120초**를 목표로 맞춰 뒀습니다.

> **공략 문법: 상대가 밟은 칸을 세다가, 바퀴가 끝나 쉴 때 때린다.**
> 되받아칠 틈은 관문마다 **1.3~1.6초**, 마왕은 평균 1.63초 · 최대 2.14초입니다.
> 1스테이지에서 이걸 배우고 마왕에서 졸업합니다.

### 성장 — 고르지 않은 것은 전부 마왕에게

레벨업 화면에는 **카드 두 장**과 **취소** 하나가 있습니다.

- **스킬 카드 A** 또는 **B** — 고른 쪽은 레일에, 버린 한 장은 마왕에게
- **취소** — 두 장을 **둘 다 버리고** 골드를 조금 받습니다. **이때는 마왕도 아무것도 못 얻습니다.**
  레일 다섯 칸이 이미 다 찼을 때의 출구입니다.

각인은 레벨업이 아니라 **각인 세공사 · 보물상자 · 균열 · 전조 격파**에서 나옵니다.
각인 3택1에서 고르지 않은 둘은 조각이 되어 마왕에게 갑니다.
랭크는 **R3 상한**(같은 카드 4장)이고 R1 ×1.00 / R2 ×1.55 / R3 ×2.10 피해입니다.

**보스 트로피** — 관문을 하나 부술 때마다 두 가지를 함께 받습니다.

- **중립 스탯 하나는 고정으로** 받습니다(스테이지가 정합니다).
- **특별 카드는 2택1**이고 **버린 쪽은 마왕에게** 갑니다.
- 다섯 개를 전부 모으면 체력 +58 · 피해 +18 · 전체 피해 ×1.29 · 치명타 +8% ·
  관통 +1 · 투사체 +1 · 수호막 +2 · 사거리 +34 · 처치 회복 +1.5가 쌓입니다.

마왕은 받은 카드를 자동 합성해 **화력 상위 5장**을 자기 레일에 올리고,
나머지는 **잔재**가 되어 필드 몹의 모듈로 뿌려집니다.

### 아이템 = 장비 4부위 (57종)

아이템은 칸을 차지하지 않습니다. **무기 · 목걸이 · 반지 · 팔찌** 각 1개를 낍니다.
효과는 레일 전체 / 바늘 기준 앞뒤 칸 / 지금 칸에 걸립니다.

- 등급은 **일반 · 희귀 · 특별 · 영웅** 넷입니다.
- 무기 성향: 레이피어는 지속·RELOAD, 대검은 피해 증폭, 단검은 연속 타격, 장검은 균형·수호, 창은 범위·관통

### 균열 · 성 · 밤 · 잠식

- **균열**(체류 1·3에 개설 · 스테이지당 2회): 접근하면 정예 3~5기.
  모두 쓸면 각인 3택1 + 60 G + 체력 전회복
- **성·캠프의 상인 넷**: 카드 상점 · 각인 세공사 · **계약자**(머문 밤을 사고팝니다) ·
  **밀정**(마왕의 다섯 칸을 보여 줍니다 — 열람은 **무료**, 칸 하나를 통째로 지우는 것만
  스테이지당 한 번 120 G). 상점가는 스테이지가 오를수록 비싸집니다
- **밤의 전조**(체류 2부터 매 밤 1기): 마왕의 다섯 칸 중 하나를 실제로 보여 주는 중형 마물.
  격파하면 **각인 뜯기**(마왕의 각인 영영 삭제)나 **카드 되찾기** 중 하나를 고릅니다
- **잠식**(체류가 스테이지 기준에 닿으면): 모든 필드 몹이 마왕의 조각과 각인을 들고 나옵니다.
  **스테이지를 깨면 풀립니다**
- **강림**(체류가 아주 깊어지면): 보스가 프리뷰 없이 필드로 내려옵니다.
  잡몹과 동시에 상대해야 하고 승리 등급이 C로 고정됩니다. 정상적인 플레이는 여기 닿지 않습니다

### 마왕

마왕은 **플레이어와 완전히 같은 런타임**을 씁니다. 5칸 · 각인 · RELOAD 전부 같습니다.
다른 것은 셋 — RELOAD가 **0.42배로 빠르고**, 늦게 도전할수록 체력이 두껍고,
**상태이상에 걸리지 않습니다.** 레일 각인은 갖지 않습니다.

> 화면 위쪽 마왕 레일 밴드가 마왕의 바늘 · **밟은 칸 수** · 되받아칠 틈을 실시간으로 보여 줍니다.

## 필드에서 벌어지는 일

- 무한 좌표 기반 지형 3벌(초원 · 황야 · 심연), 호수, 다리, 숲, 바위, 유적, 보물상자
  (Simple Tiled WFC 청크 생성)
- **바위와 물은 못 지나갑니다** — 플레이어도 마물도 같은 규칙입니다. 다리만 예외입니다.
- **몹마다 습성이 다섯 갈래**입니다: 무리 지어 다니고(3~5기가 함께 나옵니다) ·
  맞아도 도망가고 · 자기 자리를 지키고 · 숨어 있다 덮치고 · 먼저 사냥합니다.
  **1·2스테이지 낮에는 아무도 먼저 덤비지 않습니다.**
- 지형이 종을 정합니다 — 풀밭엔 무리, 숲엔 매복, 바위엔 텃세, 물가엔 겁쟁이.
- **밤**에는 습성이 사라지고 전부 몰려옵니다.
- **필드 사건 8종**이 스테이지마다 2~3개 열립니다: 작은 던전 · 보물섬 · 이름 있는 마물 ·
  유랑 상인 · 무너진 사당 · 마왕의 발자국 · 굶주린 무리 · 별똥별.
- **가 본 곳만 화살표가 켜집니다.** 성은 처음부터 켜져 있고, 걸어가면 보스문·균열·사건이
  하나씩 켜집니다.
- **소비 아이템 8종**(`Q` 한 칸): 낡은 지도 · 해시계 · 밤눈 부적 · 소환 뿔피리 ·
  회복의 빵 · 되돌이 종 · 각인 지우개 · 미끼 인형.
- 공간 해시 · 이펙트 상한 · 지속 피해 0.25초 버퍼 · 반응 예산으로 100기 이상 전투에서도
  유지되는 프레임
- **타격감**: 몹마다 넉백·경직·둔화를 받는 정도가 다르고(위습은 오우거의 17배로 날아갑니다),
  카드마다 밀치기·붙잡기·띄우기·끌어당기기 같은 충격이 붙습니다.
  카메라 흔들림은 **최대 4px · 0.12초**이고 다섯 자리에서만 흔들립니다.

## 자동 검사

```bash
bash godot-game/scripts/test/run_all.sh            # 컴파일 1 + 기능 검사 16종 (약 135초)
bash godot-game/scripts/test/run_all.sh --boss-test
bash godot-game/scripts/test/run_all.sh --captures # 시각 캡처 15종 73컷 (창을 띄웁니다)
```

종료 코드 0이면 전부 통과입니다.
검사 항목은 월드 · **필드 생태** · 5칸 덱 · 성/트로피 · 균열 · 스트레스 · 스모크 · 전투 ·
스테이지 클럭 · 상태이상 · 사이클 런타임 · 각인 드래프트 · 보스 3종과 마왕전 ·
이어하기 · 길잡이 · **필드 사건**입니다.

밸런스 근거와 규칙·데이터 계약은 별도 프로브가 계산합니다(`run_all.sh`에 안 들어갑니다).

```bash
godot --headless --path godot-game -s res://scripts/test/balance_probe.gd   # 약 90초
godot --headless --path godot-game -s res://scripts/test/rune_test.gd
godot --headless --path godot-game -s res://scripts/test/data_test.gd
godot --headless --path godot-game -s res://scripts/test/rift_probe.gd
godot --headless --path godot-game -s res://scripts/test/terrain_probe.gd -- fast   # 약 40초
```

`balance_probe` 마지막 줄의 `pass=1`이 전부 통과라는 뜻입니다.
**밸런스 숫자를 바꾸기 전에 먼저 돌립니다.**

> ⚠️ `status_test.gd`만은 `-s`로 돌리면 멈춘 것처럼 보입니다(`SceneTree`가 아닙니다).
> 정식 경로는 `godot --headless --path godot-game -- --status-test`입니다.

특정 화면만 열어 보려면:

```bash
godot --path godot-game -- --preview-boss        # 마왕 프리뷰
godot --path godot-game -- --preview-build       # 편집 화면
godot --path godot-game -- --preview-rift        # 균열
godot --path godot-game -- --preview-onboarding  # 게임 안내 4페이지
```
