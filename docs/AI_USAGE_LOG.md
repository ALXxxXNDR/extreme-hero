## 주요 디렉팅과 교정 사례

### 1. 벽돌깨기에서 의도한 장르로 복귀

- 잘못된 중간 결과: 흔한 서바이버를 피하려다 게임이 벽돌깨기로 바뀜
- 인간 피드백: 장르를 바꾸는 것이 아니라 ‘버린 선택의 귀환’으로 차별화해야 함
- 결과: Godot 기반 탑다운 액션으로 완전히 다시 구현

### 2. 뱀서류와의 차이 재정의

- AI 초안: 화면 가장자리에서 적이 계속 생성되어 플레이어를 추격
- 인간 피드백: 낮에는 몬스터가 필드에 상주하고 플레이어가 찾아가야 함
- 결과: 도주형·반격형·무리형·추적형의 네 AI와 낮/밤 상태 전환 구현

### 3. 오리지널 픽셀 디자인 방향

- 인간 지시: 파이널 판타지 시절 RPG를 회상하되 택틱스가 아닌 액션 게임
- 안전 기준: 기존 작품의 인물·몬스터·UI·로고·음악·고유 장소를 복제하지 않음
- 이미지 생성 프롬프트 핵심: `original top-down 16-bit action RPG`, `castle, river, bridge, roaming monsters`, `day-to-night raid`, `no existing characters or logos`
- 생성 결과 저장: `godot-game/art/reference/the-unchosen-visual-direction.png`
- 사용 방식: 런타임 스프라이트로 직접 사용하지 않고 색감·실루엣·낮/밤 대비의 방향 참고로만 사용

### 4. 무한 월드 구현

- AI 제안: 전체 맵을 미리 생성하지 않고 현재 카메라 주변 타일만 좌표로 계산
- 인간 요구 반영: 강은 막히고 다리에서만 통과, 성과 상자 위치 탐색, 먼 마왕성 목표
- 자동 검증: 시작 성과 마왕성 모두 상호작용 대상으로 생성, 강은 차단, 다리는 통과

### 5. 버린 선택의 범위 확장

- 기존 구조: 선택하지 않은 스킬만 보스에게 전달
- 인간 피드백: 버린 무기와 장신구도 모두 마왕이 사용
- 결과: 장착 거절 시 새 장비, 교체 시 기존 장비가 마왕 목록에 추가됨. 보스 체력·공격·속도·모듈과 시각적 궤도 아이콘에 반영

### 6. 실제 화면을 통한 밸런스 교정

- 첫 자동 전투: 움직이지 않은 검사가 낮 12초 안에 사망
- 분석: 방향 공격은 정상이나 낮의 추적형 비율이 25%로 높았음
- 수정: 낮 생성 확률을 도주 36%, 반격 32%, 무리 23%, 추적 9%로 조정
- 재검증: 무조작 12초 후에도 `state=playing`

### 7. 상자 참조 오류 발견과 수정

- 증상: 상자를 연 뒤 상호작용 사전을 비우면서 같은 사전을 참조하던 상자 위치도 사라짐
- 수정: 상자 ID와 위치를 먼저 값으로 복사한 뒤 상호작용 상태를 비움
- 재검증: 상자→성→장비 장착/버리기→밤 전환 통합 테스트 통과

### 8. 마왕성 청크 오류 발견과 수정

- 증상: 나침반 좌표는 존재하지만 청크 중앙과 마왕성 좌표를 잘못 비교해 실제 성이 생성되지 않을 가능성
- 수정: 마왕 좌표가 포함된 청크 번호를 계산해 현재 청크와 비교
- 재검증: `demon=demon_castle` 출력과 실제 상호작용 확인

### 9. 성장 피드백과 전직 수직 슬라이스

- 인간 피드백: 스킬을 중복 선택해도 성장 여부가 보이지 않고, 전직과 네 방향 전리품 시스템이 필요함
- AI 구현: 14종 코드 생성 아이콘, HUD RANK, 마왕 초상 운명 전달, 9개 전직 계보, 네 정예 캠프, 궤도 구슬, 랜덤 전승 NPC를 데이터 중심 구조로 연결
- 시각 검증: 온보딩·운명 전달·전직·시련 캠프를 실제 1280×720 창에서 확인
- 자동 검증: `branches=true first_job=true four_orbs=true second_job=true boss_jobs=2`

### 10. 흐름을 끊지 않는 UI와 입력 교정

- 인간 피드백: 필드의 보유 스킬 패널이 시야를 가리고, 스킬 선택 뒤 마왕 확인 화면을 한 번 더 닫아야 해 흐름이 끊김
- AI 구현: 필드 스킬 패널을 제거하고 `Esc` 기록 화면으로 이전, 방향키 선택과 `Space` 확정, 선택 즉시 필드 복귀, 오른쪽 아래 마왕 성장 알림 구현
- 근접 공격 오류 분석: 방향 전환 때 공격 쿨타임을 강제로 줄이던 코드가 두 번째 공격처럼 보이는 원인이었음
- 수정: 공격 시점에 방향을 한 번 기록하고, 검격 판정과 이펙트가 그 방향을 끝까지 사용하도록 변경

### 11. 대시·스킬 다양화·밤 변이

- 인간 요구: 짧고 엄격한 대시 무적, 10초 쿨타임, 머리 위 게이지, 근접 외 성장 선택지, 밤의 시각적 공포
- AI 구현: 0.14초 무적 대시와 10초 기본 쿨타임, 대시 훈련·대시 공격, 장판·오라·경험치·재생 보호막 스킬을 포함해 총 20종으로 확장
- 밤 전환: 낮 몬스터가 즉시 교체되는 대신 기존 개체의 몸색·뿔·눈·송곳니가 점진적으로 변하며 습격 AI로 전환

### 12. 실제 성 내부와 다수 개체 최적화

- 인간 피드백: 성 버튼 화면이 아니라 실제 성 안으로 들어가 랜덤 NPC를 찾아야 함. 몬스터 증가 시 렉도 미리 방지해야 함
- AI 구현: 성별로 서비스와 위치가 고정되는 NPC 3명의 실내 맵, 출구, 개별 대화창을 구현. 입장 중 바깥 전투 전체를 안전하게 정지
- 성능 구조: 공간 해시 적 조회, 통합 지속 효과 관리자, 순간 이펙트 상한, 경험치 구슬 병합, 월드·몬스터 그리기 주기 절감
- 극한 검증: 몬스터 101마리와 구슬 68개를 유지한 테스트에서 `fps=144 bounded=true structure=true`, 삭제 직전 적 참조 경고도 재현 후 제거
