# 딜싸이클 용사 — 현재 게임 기획 기준

이 문서는 2026-08-04 구현본의 기준입니다. 밸런스 수치는 플레이테스트 후 조절합니다.

## 한 문장

낮에는 마물을 찾아 성장하고 밤에는 습격을 버티며, 카드로 프로그래밍한 딜싸이클 공장과 버린 카드로 완성된 마왕 공장이 맞붙는 실시간 덱빌딩 액션 RPG.

## 플레이어 공장

- 시작 슬롯 3개, 최대 10개
- 빈 슬롯은 기본 베기
- 실행 방향은 왼쪽에서 오른쪽
- 카드 도착 즉시 발동
- 사용자 노출 시간은 `지속시간`과 `RELOAD` 두 가지
- 지속시간 = 실제 행동시간 + 행동 후 지연시간
- 카드 종료 조건 = 전체 지속시간 종료
- 한 바퀴 종료 조건 = 마지막 슬롯 종료
- 한 바퀴 뒤 대기시간 = 모든 스킬 카드의 RELOAD 합계

공식:

```text
한 바퀴 시간
= 각 슬롯에서 가장 긴 동시 카드 지속시간의 합
+ 모든 실행 스킬 카드 RELOAD의 합
```

아이템 카드가 단독으로 들어간 칸은 공격하지 않고 즉시 통과합니다. 빈칸으로 되돌리면 기본 베기가 다시 실행됩니다.

## 레벨업

선택 화면:

1. 스킬 카드 A
2. 스킬 카드 B
3. 두 카드 아래에 별도로 놓인 `스킬 선택 취소 · 공장 부품 건설` 버튼

카드 선택 시:

- 선택하지 않은 한 장은 마왕에게 전달
- 선택한 카드는 전체 레일 모달에서 즉시 배치
- 교체된 카드는 보관함 이동
- 배치 직후 필드 복귀

취소 버튼 선택 시:

- A와 B 모두 마왕에게 전달
- `다리 → 칸`을 번갈아 건설
- 처음 모양은 `칸-줄-칸-줄-칸`
- 첫 포기 뒤 `칸-줄-칸-줄-칸-줄`
- 두 번째 포기 뒤 네 번째 칸 완성
- 10칸까지 총 14회 필요

## 카드와 합성

- 일반 기술 카드 28종
- 전직 특별 카드 12종
- 같은 기술·같은 RANK 두 장 → 다음 RANK 한 장
- 최대 RANK 5
- 선택지에 총 보유 장수와 최고 RANK 표시
- 보관함과 딜사이클에 배치한 카드를 모두 보유 카드로 계산
- 카드마다 서로 구분되는 픽셀 아이콘 표시
- 짧은 일반 스킬도 최소 0.8초 이상 진행하며, 빠른 기술은 2회 이상 공격
- 베기, 투사체, 장판, 끌어당김, 둔화, 밀치기, 회복, 연속 타격 등 서로 다른 전투 행동 제공

## 아이템 카드

아이템은 스킬에 포함되지 않는 독립 카드입니다. 별도 장비 칸 없이 스킬과 같은 딜사이클 칸을 차지하며, 그 칸에서 공격하지 않고 배치 관계나 영구 능력치를 수정합니다.

- 무기: 레이피어, 대검, 단검, 장검, 창
- 액세서리: 목걸이, 반지, 팔찌
- 레이피어: 지속시간과 RELOAD 단축
- 대검: 높은 피해 증폭과 시간 리스크
- 단검: 타격 수와 연속 실행
- 장검: 균형과 방어
- 창: 범위와 관통
- 무기·액세서리 다수: 전체 딜사이클 RELOAD 감소
- 적용 범위: 같은 칸, 앞 칸, 뒤 칸, 인접 칸 또는 전체 딜사이클

레어도 및 수량:

| 레어도 | 색 | 수량 |
|---|---|---:|
| 커먼 | 회색 | 21 |
| 레어 | 파랑 | 15 |
| 유니크 | 보라 | 12 |
| 히어로 | 빨강 | 9 |

총 57종.

## 분열과 슬롯 강화

- 런 전체에서 분열 업그레이드 2회
- 같은 슬롯에 두 번 적용 가능
- 슬롯당 최대 3개 동시 카드
- 다음 슬롯 이동 시점은 동시 카드 중 가장 긴 지속시간 종료 시점
- RELOAD는 동시 카드 각각을 모두 합산
- 아이템을 동시 줄에 넣어 같은 칸의 스킬 강화 가능

강화술사 판매 항목:

- 다음 다리/칸
- 동시 레일 +1
- 슬롯 전체 2회 실행
- 슬롯 지속시간 -14%
- 슬롯 RELOAD -18%

## 근접 공격 방향

- 공격 시작 방향을 고정하지 않음
- 실행 중 매 프레임 현재 이동 입력 방향을 확인
- 공격의 경과시간은 유지
- 범위와 이펙트만 회전
- 방향 전환으로 공격을 새로 생성하지 않음
- 기본 한 타격 구간당 같은 적 한 번
- 카드에 다단 횟수가 있으면 타격 구간을 분리

## 성

- E는 입력문자와 물리키 위치를 모두 지원
- 성 정보를 상호작용 데이터와 독립 복사한 후 입장
- 필드 전투 정지, 실제 실내 맵 이동
- 카드 합성 장인은 모든 성에 등장
- 나머지 NPC 세 명은 성마다 결정
- 카드 상점은 성별 상품 상태 유지
- 유료 새로고침
- 가격, 등장률, 골드 수급은 임시값

## 전직

1차:

- 지정 R5 기술 카드 두 장
- 대응 무기 종류 한 장 보유
- 조건 충족 즉시 자동 전직
- 기술 카드 두 장 소모
- 무기 유지
- 특별 카드 2지선다
- 선택하지 않은 특별 카드는 마왕에게 전달

2차:

- 동서남북 캠프 전멸
- 네 구슬이 몸 주위를 회전
- 구슬 네 개 획득 후 전승 현자 등장 확률 약 90%
- 현자에게 구슬 전달
- 강력한 2차 특별 카드 2지선다
- 선택하지 않은 카드 마왕 전달

## 마왕

- 진입 전에 전체 공장 공개
- 일반 슬롯 10개
- 각 슬롯 두 줄, 총 20칸
- RELOAD 없음
- 동일한 버림 카드 자동 합성
- 예상 DPS와 범위·방어 유틸리티로 카드 우선순위 정렬
- 버린 아이템 카드를 동시/인접 버프로 배치
- 마지막 슬롯 뒤 즉시 첫 슬롯 반복
- 현재 버전은 의도적인 상한 난이도이며 후속 밸런스 대상

## 유지 시스템

- 무한 월드, 물길, 다리, 성, 보물상자
- 낮 탐색과 밤 습격
- 네 행동 유형, 13종 몬스터
- 대시와 짧은 무적
- 동서남북 캠프
- 몬스터 공간 해시와 효과/경험치 구슬 상한

## 화면 표시 원칙

- 카드 설명은 이름, 종류, 핵심 효과, 피해·범위 순으로 분리
- `지속시간`은 청록색 막대, `RELOAD`는 주황색 막대로 구분
- 전투 HUD에는 현재 스킬의 진행률 또는 남은 RELOAD가 막대로 표시
- 아이템 카드에는 `공격 없음`, 적용 범위, 핵심 강화 수치를 표시
- 긴 이름과 설명은 정해진 영역 밖으로 흘러나오지 않도록 말줄임 또는 줄바꿈 처리

## 후속 플레이테스트에서 조절할 값

- 레벨업 경험치 곡선
- 카드별 피해·지속시간·RELOAD 세부 수치
- 아이템별 정확한 강화 수치
- 레어도별 드랍률
- 상점 가격과 새로고침 비용
- 골드 수급량
- 마왕 체력과 카드 피해 배율

이 값들은 실제 플레이 후 바꾸되, 데이터 파일 중심으로 조절할 수 있게 분리했습니다.
