# v1의 전직 조건(R5 카드 2종 + 대응 무기 / 동서남북 시련 구슬 4개)은 7일 런에서
# 물리적으로 도달 불가라 **시간 이정표 + 가벼운 태그 조건**으로 교체했다.
#
#   1차 각성 : 3일차 새벽 (조건 없음) → 계보 3종 택1 → 특별 카드 2택1 + 스탯
#   2차 각성 : 6일차 새벽 (해당 계보 원소 칸의 각인 3개 이상) → 특별 카드 2택1 + 스탯
#
# **데이터 구조는 v1 그대로다.** 3계보 · tier1/tier2 이름 · choices 4종 × 3계보
# (= SPECIALS 12종) · effects · color 전부 유지했고, 참조를 끊은 것은 세 키뿐이다:
#   `weapon_type` (무기 조건 폐기) · `skills` (R5 재료 카드 폐기) · `rank` (R5 폐기)
#
# 대신 `element`가 들어왔다. 계보 = 원소 축이다(handoff-w7 §1 "설계 의도 하나"):
#   성기사 = 광(light) · 광전사 = 혈(blood) · 창기사 = 철(iron)
# 12종 특별 카드의 `element`도 전부 계보 원소로 맞춰져 있어, 각성하면 그 원소의
# 결속·공명이 자연스럽게 강해진다.
#
# 계보 선택 추천 순서는 `game.gd::_lineage_affinity()`가 보유 카드의 원소 분포로
# 계산한다(이 파일은 데이터만 들고 있는다).

static func all() -> Array[Dictionary]:
	return BRANCHES.duplicate(true)

static func by_id(id: String) -> Dictionary:
	for branch: Dictionary in BRANCHES:
		if branch["id"] == id:
			return branch.duplicate(true)
	return {}

static func for_base(base_id: String) -> Array[Dictionary]:
	var result: Array[Dictionary] = []
	for branch: Dictionary in BRANCHES:
		if branch["base"] == base_id:
			result.append(branch.duplicate(true))
	return result

## 계보 원소(`RuneEngine.ELEMENTS`의 한 값)로 계보를 찾는다.
static func by_element(element: String) -> Dictionary:
	for branch: Dictionary in BRANCHES:
		if branch["element"] == element:
			return branch.duplicate(true)
	return {}

## 각성 조건이 열리는 일차. tier 1 -> 3, tier 2 -> 6.
static func unlock_day(tier: int) -> int:
	return AWAKENING_TIER2_DAY if tier >= 2 else AWAKENING_TIER1_DAY

## 그 tier가 요구하는 계보 태그 각인 수. 1차는 조건 없음(0).
static func required_rune_tags(tier: int) -> int:
	return AWAKENING_TIER2_RUNE_TAGS if tier >= 2 else 0
