# 딜싸이클 용사 — Godot 프로젝트

Godot 4.7.1과 GDScript로 만든 플레이 가능한 액션 덱빌딩 프로토타입입니다.

## 실행

1. Godot에서 `project.godot`을 Import합니다.
2. 오른쪽 위의 프로젝트 실행 버튼을 누릅니다.
3. 온보딩을 읽고 `모험 시작`을 누릅니다.

터미널 실행:

```bash
godot --path .
```

## 조작

- 이동/공격 방향: `WASD` 또는 방향키
- 대시: `Shift`
- 상호작용: 물리키 `E`
- 전체 딜싸이클 공장: `Esc`
- 선택: 방향키, `Space`
- 공장 레일/보관함 전환: `Tab`

## 핵심 규칙

- 처음 세 빈칸은 기본 베기를 실행합니다.
- 카드가 왼쪽부터 지속시간만큼 실행됩니다.
- 끝에서는 모든 스킬의 RELOAD를 더해 쉰 뒤 다시 시작합니다.
- 레벨업 카드 선택 직후 전체 레일에서 갈아 끼우고 필드로 돌아갑니다.
- 두 스킬 카드 아래의 `딜싸이클 업그레이드`를 누르면 둘 다 마왕에게 주고 다리와 칸을 번갈아 건설합니다.
- 3칸에서 10칸까지 총 14개 부품이 필요합니다.
- 분열을 같은 칸에 두 번 적용하면 최대 세 카드가 동시에 실행됩니다.
- 아이템 카드는 스킬과 별개로 보유하며 같은 딜사이클 칸에 배치합니다.
- 아이템 칸은 공격하지 않고 같은 칸·앞뒤 칸·전체 딜사이클을 강화합니다.
- 일반 스킬 28종과 검사 아이템 57종은 각각 구분되는 픽셀 아이콘을 사용합니다.
- 지속시간은 청록색, RELOAD는 주황색 막대로 표시됩니다.
- 마왕은 버린 카드로 10×2칸을 구성하고 RELOAD 없이 반복합니다.

## 무한 맵 생성

- 플레이어 주변의 14×14 타일 청크만 Simple Tiled WFC 방식으로 생성합니다.
- 후보가 가장 적은 칸부터 하나를 결정하고, 상하좌우 연결 규칙을 주변 칸에 전파합니다.
- 청크 가장자리는 보편 연결 잔디 타일로 맞춰 어느 방향으로 이동해도 이음새가 끊기지 않습니다.
- 같은 좌표는 같은 월드 시드를 사용하므로 멀리 갔다 돌아와도 같은 지형이 다시 만들어집니다.
- 멀어진 청크는 메모리에서 제거하며 최대 72개까지만 보관합니다.

상세 규칙과 비개발자용 실행 설명은 상위 폴더의 `README.md`를 확인하세요.
